# LocalFinance product film

`localfinance-explainer.mp4` is the 60-second, 1080×1920, 30fps product explainer embedded in the homepage hero. It is self-hosted H.264/AAC with fast-start metadata. The JPEG is its poster; the WebVTT contains English captions. The video also has burned-in captions, so the optional caption track is not enabled by default.

Editable Remotion source, script, claims, soundtrack provenance, reproduction commands and inspection evidence are in [`video-production/localfinance-explainer`](../../video-production/localfinance-explainer/README.md).

All transactions are fictional and graphics are illustrative reconstructions. Narration is locally synthesized with Kokoro v1.0 af_heart (Apache-2.0 model / MIT engine); score and sound effects are original. Existing repository logo and bundled Inter font are reused. No external player or media service is required.
